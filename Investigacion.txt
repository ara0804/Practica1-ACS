Archivo de investigacion de 3 herramientas de ACS
1. Azure DevOps
Funcionalidades principales: Desarrollada por Microsoft, Azure DevOps es una plataforma integral de Gestión del Ciclo de Vida de las Aplicaciones (ALM). A diferencia de herramientas enfocadas únicamente en el código, unifica el trabajo técnico en componentes modulares: Azure Boards (planificación ágil con tableros Kanban/Scrum), Azure Repos (repositorios Git o TFVC), Azure Pipelines (CI/CD multiplataforma), Azure Artifacts (gestión de dependencias y paquetes) y Azure Test Plans (pruebas manuales, exploratorias y sistemáticas).

Ventajas competitivas: Su principal fortaleza es la trazabilidad nativa de extremo a extremo. Permite rastrear una línea de código en producción hasta el caso de prueba que la validó, el commit Git que la implementó y la tarea o requerimiento original en el tablero ágil. Además, ofrece políticas de seguridad corporativas estrictas y controles de acceso basados en roles.

Caso de uso ideal: Entornos corporativos robustos o proyectos de software complejos, como plataformas PropTech que interactúan con múltiples bases de datos relacionales, servicios backend y APIs externas como OpenStreetMap.

2. Puppet
Funcionalidades principales: Puppet es una herramienta de gestión de configuración que permite automatizar el aprovisionamiento, la configuración y la gestión operativa de servidores. Funciona bajo el paradigma de Infraestructura como Código (IaC), por lo que los administradores escriben código para describir cómo debe ser la configuración de los sistemas.

Ventajas competitivas: Reduce el trabajo manual, estandariza configuraciones y mejora la consistencia entre servidores. También facilita la automatización de tareas repetitivas y el mantenimiento de entornos a gran escala.

Caso de uso ideal: Infraestructuras con muchos servidores o entornos que requieren configuraciones repetibles, controladas y auditables.

3. Jira
Funcionalidades principales: Jira es una herramienta de Gestión de Proyectos y Seguimiento de Incidencias (Issue Tracking) desarrollada por Atlassian. Su propósito principal es ayudar a los equipos de software a planificar, rastrear, construir y lanzar productos utilizando metodologías ágiles como Scrum o Kanban.

Ventajas competitivas: Centraliza la gestión de tareas, incidencias y avances del equipo en tableros visuales. También permite priorizar trabajo, asignar responsables y dar seguimiento al progreso de cada actividad.

Caso de uso ideal: Equipos de desarrollo que necesitan organizar su trabajo diario, administrar incidencias y coordinar entregas bajo metodologías ágiles.
